# basic-firestick-launcher
I recently made this firestick launcher cause why not. It has basic functions like holding down the select button has an option to uninstall or move. There is also a flip clock on the top right of the screen. (ONLY WORKS ON FIRE STICK 2ND GEN)
Also, to install the apk, Make sure you have android tools installed, Then run "adb connect "your-firestick-ip":5555.
