# basic-firestick-launcher
I recently made this firestick launcher cause why not. It has basic functions like holding down the select button has an option to uninstall or move. There is also a flip clock on the top right of the screen. (ONLY WORKS ON FIRE STICK 2ND GEN)
Also, to install the apk, Go to your firestick's settings, then go to "My Fire TV", then go to about then click on "Fire TV Stick" as many times as you have to to make yourself developer, then go back 1 menu then click developer options, then enable ADB debugging and Apps from Unknown sources. Then, make sure you have android tools installed, Then run "adb connect "your-firestick-ip":5555.
